CeloTags Protocol Documentation

CeloTags is the open, sovereign identity and autonomous execution infrastructure for software agents across Africa and Latin America on the Celo blockchain.

Unlike traditional domain name systems (DNS or Ethereum Name Service) which stop at human-to-wallet address mapping, CeloTags provides machine-readable capability manifests (ERC-8004), native stablecoin gas abstraction (CIP-64), and cryptographic bounded execution grants.

Core Invariant: Identity is Not Authority.
A registered sovereign tag gives an agent a verifiable on-chain identity, but never blank-check access to user capital. Every financial action requires a cryptographically bound PermissionGrant.

SDK Quickstart

Install the official client library via npm, pnpm, or bun:

npm install @nairatag/celotags-protocol # or pnpm add @nairatag/celotags-protocol

Resolve any sovereign tag in TypeScript with automatic Celo Sepolia routing:

import { CeloTagsRegistry } from '@nairatag/celotags-protocol'; const registry = new CeloTagsRegistry({ rpcUrl: 'https://forno.celo-sepolia.celo-testnet.org', registryAddress: '0xb34518cC33314ee63841120bDd3Baa3BD1baf9e0' }); // Resolve forward tag const profile = await registry.resolveTag('₦chief_arbitrage'); console.log('Controller:', profile.owner); console.log('Currency Token:', profile.namespace.settlementToken); // cUSD console.log('ERC-8004 Manifest:', profile.erc8004Manifest);

ERC-8004 Machine Manifest

Every sovereign tag exposes a machine-readable capability manifest conforming to the ERC-8004 specification at /.well-known/celotag-agent.json:

{ "protocol": "celotags-v1", "standard": "ERC-8004", "handle": "₦chief_arbitrage", "owner": "0x742d35Cc6634C0532925a3b844Bc454e4438f44e", "capabilities": ["arbitrage-v1", "oracle-v1", "escrow-v1"], "endpoints": { "resolve": "https://celotags.nairatag.ng/api/celotags/resolve/₦chief_arbitrage", "manifest": "https://celotags.nairatag.ng/.well-known/celotag-agent.json?tag=₦chief_arbitrage" }, "settlement": { "network": "celo-sepolia", "chainId": 11142220, "feeCurrency": "cUSD" } }

CIP-64 Local Gas Abstraction

On Celo, transactions can specify an alternative ERC-20 token for gas payments via CIP-64. Agents executing transactions with the CeloTags SDK do not need native CELO:

  • Gas fees are deducted directly from the agent's cUSD, cEUR, or cREAL balances.
  • Sub-cent average costs (< $0.001) allow high-frequency monitoring and automated micro-tasks.
  • Native integration with Opera MiniPay allows seamless mobile-first wallet execution.

Bounded Authority & PermissionGrants

Agents act strictly as delegates under an EIP-712 typed PermissionGrant:

// EIP-712 Typed Data Structure const PermissionGrant = { agentTag: '₦chief_arbitrage', owner: '0x742d35Cc6634C0532925a3b844Bc454e4438f44e', spendCap: parseUnits('50.0', 18), // Max 50 cUSD maxPerTx: parseUnits('50.0', 18), // Max 50 cUSD per tx allowedContracts: [ '0x5b73C5498c1E3b4dbA84de0F1833c4a029d90519' // Escrow ], expiresAt: 1760000000, // Unix timestamp nonce: 42 // Anti-replay };

If an agent attempts an execution exceeding its spend cap, targeting an unapproved contract, or using an expired grant, the on-chain kernel reverts atomically.

ElizaOS Plugin

Connect CeloTags to your ElizaOS agent runtime using the official plugin:

import { AgentRuntime } from '@elizaos/core'; import { createCeloTagsPlugin } from '@nairatag/celotags-protocol/adapters'; const runtime = new AgentRuntime({ plugins: [ createCeloTagsPlugin({ rpcUrl: 'https://forno.celo-sepolia.celo-testnet.org', tag: '₦chief_arbitrage', escrowContract: '0x5b73C5498c1E3b4dbA84de0F1833c4a029d90519', maxSpendPerTx: '50.0' }) ] });

LangChain Toolkit

Instantiate structured tools for agent reasoning and tool-calling loops:

import { createCeloTagsToolkit } from '@nairatag/celotags-protocol/adapters'; import { AgentExecutor } from 'langchain/agents'; const tools = createCeloTagsToolkit({ agentPrivateKey: process.env.AGENT_PRIVATE_KEY, escrowAddress: '0x5b73C5498c1E3b4dbA84de0F1833c4a029d90519' }); // Provides resolveCeloTag, verifyDeliverable, and executeTask tools const executor = new AgentExecutor({ agent, tools });
